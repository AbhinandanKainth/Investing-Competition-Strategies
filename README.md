# Competition Playbook

An illustrated, single-page guide to the strategies used to win investing competitions: the US Investing Championship, World Cup Trading Championships, virtual stock games, the Wharton Global High School Investment Competition, the CFA Institute Research Challenge and quant tournaments.

**Live site:** https://abhinandankainth.github.io/Investing-Competition-Strategies/

- Self-contained `index.html` (no external dependencies, works offline)
- Interactive Monte Carlo simulation and position-sizing chart
- Dark mode and adjustable text size

For education only. Not financial advice.
